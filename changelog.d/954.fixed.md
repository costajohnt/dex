**`transform plan` measures a model that builds rows from an inline `VALUES` list.** A comparison mart that forms its windows with `cross join (values (7), (28)) as windows (window_days)` had every change on it reported as `attributed: false` with "unsupported FROM source: Values", because the query firewall knew no such source. A named, literal-only `VALUES` list reads nothing from the warehouse, so the firewall now admits it beside tables, views and CTEs, and the model's predicate, join and `GROUP BY` changes get their measured `rows` and `delta`. A list whose rows read a column or a subquery, or whose columns are unnamed, is still refused.
